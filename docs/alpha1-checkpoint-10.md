# v1.7 Alpha 1 checkpoint 10: WORLD SURFACES

Based on the user-approved CP09. F8 / Experimental 3D world now rasterizes floor and ceiling quads as well as the existing wall faces. The same map upload revision controls the cached geometry; cells used by collision-only decorations and modeled door openings retain horizontal surfaces. Each horizontal surface has a distinct G-buffer tag; the resolve pass uses its exact analytical plane depth for UVs and occlusion rather than half-float quantization. The previous analytic scenery path remains a fallback when no triangle hits a pixel (e.g. near/far clipping). The original F8-off path, existing lighting, settings, collision, PBR approximation and post-processing remain intact. All geometry uses current constant room height (1 world unit); variable heights and full PBR are not implemented. Separate wall/plane triangle statistics are exposed via window.CatroomsTerrainExperiment. This is a hybrid renderer, not a finished general-purpose 3D engine.

GPU visual validation: pending physical GPU test; mock tests cannot validate WGSL compilation or rendered pixels. Suggested manual test: F8 in multiple sectors, look up/down, near walls and doors, Safe Room fire, compare frame rate and switch back. ULTRA selects F8; HIGH remains as before.
