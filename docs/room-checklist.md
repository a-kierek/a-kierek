# THE CATROOMS v1.8 Beta · checklista sektorów

## W becie

- [x] Yellow Corridors · krzesło, komputer, telefon, drukarka i szafa serwerowa.
- [x] Flooded Complex · niecka dopasowana do modelu basenu, woda poniżej posadzki i chodnik wokół. Prysznic awaryjny oraz zbiornik w pomieszczeniach technicznych.
- [x] Bloody Zone · reaktor, turbina, generator i metalowe skrzydła istniejących bram.
- [x] Chrum Sector · istniejące wyposażenie i własna paleta docelowa.
- [x] Last Encounter · łóżko w klinice, szafa i okno jako wyposażenie.
- [x] Piętra techniczne · modele schodów i balustrady przy istniejących przejściach między piętrami.
