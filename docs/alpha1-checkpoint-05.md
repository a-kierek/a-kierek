# v1.7 Alpha 1 / Checkpoint 05: True Perspective & Lighting 2.0 (prototype)

Owner confirmed CP04 works and supplied an 8.5-second clip showing unnatural vertical camera projection. CP05 replaces the old screen-space horizon shift with a real pitch rotation in radians (±75°), using a shared WGSL camera basis, a horizontal-FOV projection with aspect correction, and common camera-space depth. Both terrain backends, imported meshes and upright billboard sprites use it. Floor/ceiling ray-plane intersection now limits visible wall and furniture hits and writes actual surface depth. The current CPU sprite-instance buffer remains eight floats; its first four fields are now camera-space center and world-space dimensions, not screen-space bounds. Geometry remains optional via F8; floors and ceilings are still ray-traced, not rasterized. The apparent vertical field of view at the same horizontal FOV may differ from earlier checkpoints.

Lighting prototype (F10, default on; menu keeps classic lighting): up to four nearby procedural fixture samples and one nearby Safe Room fire, distance attenuation, surface-normal Lambert-style diffuse and a roughness-dependent specular approximation, sector colors, deterministic flickering and blackout response. All terrain, mesh and billboard passes use the same lighting function. F8/F9/F10 are independent and nonpersistent. F10 off restores the old lighting style, not the old camera. No new gameplay mechanics, maps, save keys or asset requirements. The game retains the base release label internally.

Limitations: no light occlusion/shadow maps yet; fixtures in adjoining spaces can illuminate through walls; no full PBR/linear HDR workflow, normal/roughness texture maps, directional flashlight, reflections or volumetric effects. This build still needs actual WebGPU shader compilation, visual inspection and FPS testing on the owner's RTX 5060 Ti. The automated tests exercise JavaScript, numerical projection, asset/build integrity and a mock GPU only.

Suggested test: compare F10 at the same location, look up/down while close to a wall and near a rock, test F8 both ways at steep pitch, test a wide FOV and a Safe Room. Record any visual artifacts or startup shader errors and FPS at identical graphics settings.
