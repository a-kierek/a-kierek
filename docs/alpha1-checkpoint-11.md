# v1.7 Alpha 1 checkpoint 11: PBR & NORMAL MAPPING

Based on CP10, with both classic and experimental F8 terrain paths sharing CP11 materials. F9 / HD materials + PBR selects 12 new packed 512x512 opaque normal XY / roughness maps, with ten mip levels. Normal XY is reconstructed and normalized in the appropriate wall or horizontal tangent basis. Procedural source maps are regenerated by `python tools/generate_surface_details.py` (Pillow + NumPy); they approximate relief from the original albedo, rather than measured PBR assets. The terrain uses dielectric GGX with Schlick Fresnel and Smith-Schlick geometry, a bounded specular term, diffuse energy scaling, per-texel roughness and a simple ambient approximation. Linearized material shading returns to the existing display-referred fog/post-processing convention. This is not a fully color-managed HDR/PBR pipeline. Light positions, grid occlusion including closed doors, and flashlight state remain unchanged; geometric normals prevent lighting the back of a surface. F9 disables new maps and the new material shader path along with HD albedo. If the detail atlas fails to load, HD albedo and the previous lighting are retained, using the classic wall atlas as a fallback binding. No new dependencies to run the game. Existing menu/pause settings use the same preference key as CP09.

Limitations: no metalness/emission/AO maps, no PBR on mesh props, sprites, doors, safe-room brick or procedural furniture, no new reflections, no change to map geometry or collisions. Relief is visual only. Both legacy and F8 geometry are supported. Added detail atlas uses approximately 16 MiB GPU memory with full mip chain. Diagnostics: `window.CatroomsPBR.available`, `.enabled`, `.error`. `.enabled` reports HD/PBR selection, not whether lighting is enabled. Actual WGSL compilation and rendered pixels still require a supported WebGPU browser; local browser navigation is blocked by administrator policy. Reference BRDF tests do not execute the shader itself.

Manual verification: inspect floor, ceiling and wall under flashlight in sectors 1 and 2; compare F9 in each F8 mode; check closed doors and Safe Room fire; verify FPS and loading errors. CP10 unchanged as rollback.
