# v1.7 Alpha 1 / checkpoint 07: Flashlight & Decor Variation

Based on checkpoint 06 (user confirmed working on RTX 5060 Ti). F6 toggles the new spotlight, enabled by default; F7, F8, F9 and F10 remain independent. Existing flashlight gameplay input, detection and saves are unchanged. The new beam is applied to terrain, furniture, sprites and meshes, with a 12–25 degree soft angular falloff, distance attenuation (11 tiles maximum), wall visibility, time-smoothed intensity and small walking sway. It is not a volumetric light. There is no new battery resource or battery drain. Caster occlusion is still limited to full-height map walls, not dynamic meshes or moving doors. The menu retains the old rendering. F6 restores the previous flashlight shading.

Box scale 0.48–0.60, CRT scale 0.55–0.67, yaw 0–360 degrees, 38% chance of a 90-degree side tilt, with bounded random offsets. Their positions and poses use seeded generation. Both remain solid tile-based obstacles (the existing conservative collision system), rather than mesh-shaped collision. The model shader rotates positions and normals together; ground elevation is adjusted using the original symmetric model bounds. No new assets required. The model size and actual per-vertex bounds are tested against the tile and floor. No changes to gameplay progression or displayed base version.

Test limitations: release suite is CPU/static/HTTP; browser smoke uses a mocked GPU. Real WGSL compilation, appearance and performance require testing on the user's GPU. No claim of full PBR, shadow maps or volumetric flashlight.
