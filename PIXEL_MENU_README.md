# CATROOMS / PIXEL HORROR MENU

Nowy ekran startowy: CATROOMS + PRESS START. Następnie zakładki GRAJ / USTAWIENIA / GRACZ. Graj zachowuje przełącznik NORMAL/HARD i poziomy. Ustawienia otwierają oryginalny, aktywny panel ustawień. Gracz zmienia lokalnie zapisaną nazwę.

CSS: `css/pixel-menu.css`; logika przełączania menu: `js/ui/pixel-menu.js`; HTML: `index.html`. Kod gry i wyłączone CO-OP pozostały zachowane.

Generator pojedynczego HTML: `python tools/build_standalone.py`.
